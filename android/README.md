# 📱 ManjarVPN — نسخه‌ی اندروید (v1.8.0)

همان برنامه‌ی ویندوزی، این‌بار به‌صورت یک اپ اندروید بومی با **تونل VPN واقعی**.

## ✨ امکانات (یکسان با ویندوز)

- 🛡 **اتصال خودکار**: دریافت کانفیگ‌های رایگان از ۳۹ منبع زنده ← پیش‌فیلتر TCP ← پینگ موازی ← **تست عمیق** (باز کردن واقعی یوتوب/اینستاگرام/تلگرام + سرعت دانلود/آپلود) ← بهترین سرور ← **تونل VPN**
- ⏳ اسپلش ۷ ثانیه‌ای با پیام‌های چرخشی
- 🖥 همه‌چیز وسطِ صفحه و راست‌چین با فونت وزیرمتن
- 🎁 گردونه‌ی هدیه‌ی خوش‌آمدگویی (۵۰۰ تا ۶۰۰ مگ — فقط یک‌بار برای هر سیستم)
- 📦 محاسبه‌گر مصرف حجم با API آمار خودِ Xray
- 💳 کد شارژ: `Manjar172026` ← +۷ گیگ | `Manjar172026Admin` ← +۲۰ گیگ (مکرر)
- ⛔ اتمام اعتبار = قطع سرویس تا شارژ مجدد
- 🍔 منوی همبرگری: فیلترشکن (VPN) • Game Booster (به‌زودی) • App Booster (به‌زودی) • راهنمای کامل
- 💡 نوتیفِ راهنمای اتصال هنگام باز شدن
- 🤖 سوییچ «نجات با AI» (پیش‌فرض خاموش) — مثل ویندوز از سرویس رایگان Pollinations
- 🔧 نگهبان اتصال + تعمیر بی‌صدای سرور + حالت اضطراری + گزارشِ قیفِ تست
- 📄 کانفیگ دستی (VLESS/VMess/Trojan/SS یا لینک اشتراک) + پنل سرورهای تست‌شده

## 📲 نصب

1. فایل `ManjarVPN-1.8.0-android.apk` را از [Releases](https://github.com/Amirxhossein88/manjar-vpn/releases) دانلود کنید (اندروید ۷ به بالا — arm64).
2. اجازه‌ی «نصب از منابع ناشناس» را بدهید و نصب کنید.
3. دفعه‌ی اول که «اتصال خودکار» را می‌زنید، اندروید پنجره‌ی اجازه‌ی VPN نشان می‌دهد — **اجازه دادن** را بزنید.

> روی اندروید به‌جای «پروکسی سیستم» ویندوز، **VpnService واقعی** فعال می‌شود؛ یعنی همه‌ی برنامه‌های گوشی (تلگرام، یوتوب، بازی‌ها…) بدون هیچ تنظیمی از تونل رد می‌شوند.

## 🏗 معماری فنی

```
WebView UI (index.html — پورتِ کاملِ main.py)
        │  JS Bridge «Manjar»
        ▼
MainActivity ──► ManjarVpnService (VpnService)
                    │
                    ├─► هسته‌ی Xray رسمی (libxray.so — زیرپروسه)
                    │     socks: 127.0.0.1:10808 + API آمار: 15432
                    │
                    ├─► ProtRelay — رله‌ی محافظ: خروجیِ Xray با
                    │     VpnService.protect() به سرور واقعی وصل می‌شود
                    │     (SNI/Reality دست‌نخورده — جلوگیری از حلقه‌ی TUN)
                    │
                    └─► hev-socks5-tunnel (JNI) — بسته‌های TUN را
                          به socks محلی می‌برد (MTU 8500، UDP)
```

- موتورِ تست (قیفِ پینگ ← سایت ← سرعت) یک‌به‌یک از `engine.py` ویندوز پرت شده و
  با تستِ خودکار در برابر نسخه‌ی پایتون **صحت‌سنجی شده** است (۷۳۳۹ از ۷۳۳۸ کانفیگ، پارسِ یکسان؛
  کانفیگ Xray خروجی بایت‌به‌بایت یکسان).
- حسابِ اعتبار (`account.py`) هم پرت شده: SharedPreferences + نسخه‌ی آینه‌ای در
  `Download/ManjarVPN/account.json` برای ماندگاریِ گردونه/مصرف بعد از نصبِ مجدد (در حدِ امکاناتِ اندروید).

## 🔨 بیلد (بدون Gradle)

پیش‌نیازها: JDK 17، Android SDK (build-tools 34.0.0 + platform 34)، Xray اندروید arm64
(از ریلیزهای رسمی XTLS/Xray-core) و hev-socks5-tunnel (AAR + کتابخانه‌ی JNI از ریلیزهای heiher).

```bash
# متغیرها را مطابق مسیر SDK خودتان تنظیم کنید
bash android/build_android.sh
```

اسکریپت: aapt2 compile/link ← javac ← d8 ← بسته‌بندی ← zipalign ← apksigner.
خروجی: `android/build/ManjarVPN-1.8.0-android.apk`
