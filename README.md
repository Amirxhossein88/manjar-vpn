# 🛡 ManjarVPN

برنامه‌ای برای ویندوز با **یک دکمه**: اینترنت شما را خودش بررسی می‌کند، کانفیگ‌های رایگان عمومی دنیا (جمع‌آوری‌شده از کانال‌های تلگرامی توسط مخازن معتبر) را دریافت و با **تست کامل پینگ + باز کردن واقعی یوتوب/اینستاگرام/تلگرام + سرعت واقعی دانلود و آپلود** بهترین کانفیگ را پیدا می‌کند، به آن وصل می‌شود و پروکسی کل سیستم ویندوز را روشن می‌کند.

## 🆕 چه چیزهایی در v1.4.0 تغییر کرد؟

- 🎯 **تست عمیق هر کاندید قبل از اتصال**: برنامه با هر کاندیدِ کم‌پینگ، یک هسته Xray بالا می‌آورد و از داخل همان تونل **یوتوب، اینستاگرام و تلگرام را واقعا باز می‌کند** (حداقل ۲ از ۳)، بعد **سرعت دانلود و آپلود واقعی** را می‌سنجد و فقط به سروری وصل می‌شود که هم پینگ کمتر، هم سرعت بیشتر، هم سایت‌ها را واقعا باز کرده باشد — ضد «وصل شد ولی هیچی کار نمی‌کند»
- 🖼 **رفع باگ چپ‌چین بودن کارت سرور**: متن «انتخاب خودکار بهترین سرور» حالا کاملا **وسط‌چین** است
- 📋 **رفع باگ «لیست سرورها هیچی نشان نمی‌داد»**: پنجره‌ی جدا CTkToplevel که روی بعضی ویندوزها خالی/معلق می‌شد، حذف شد؛ پنل «سرورهای تست‌شده» حالا **داخل خود پنجره‌ی اصلی** باز می‌شود، نتایج **زنده و وسط تست** پر می‌شوند، دکمه‌ی «✕ بستن» و کلید Escape هم دارد و هر ردیف پینگ/دانلود/آپلود/سایت‌های باز‌شده‌ی همان سرور را نشان می‌دهد
- ✖ **رفع باگ کار نکردن دکمه‌ی ضربدر**: بستن برنامه قبلا وسط کشتن ده‌ها پروسه‌ی Xray روی ترد رابط هنگ می‌کرد؛ حالا پنجره **فورا بسته می‌شود**، پروکسی سیستم بلافاصله خاموش می‌شود و پروسه‌های تست در پس‌زمینه و بدون رهاشدن جمع می‌شوند
- 🧠 **مسیر سریع هوشمندتر**: حافظه‌ی سرورهای خوب قبلی هم حالا قبل از اتصال، تست کامل سایت‌ها + سرعت دان/آپ را پاس می‌کند
- 🏷 بیلد خودکار Release با پوش تگ (`v*`) در GitHub Actions

## ⚙️ چی درست می‌شود؟

فایل `ManjarVPN.exe` (تک‌فایل، بدون نیاز به نصب پایتون) که **هسته Xray داخلش باندل شده** و ساختنش با **GitHub Actions** به‌صورت خودکار انجام می‌شود.

## 🚀 ساخت exe با GitHub Actions — روش بدون گیت (ساده)

1. وارد [github.com](https://github.com) شوید و ثبت‌نام/ورود کنید.
2. دکمه `+` بالا سمت راست → **New repository** → اسم دلخواه (مثلاً `manjarvpn`) → Public → **Create repository**.
3. در صفحه جدید روی **«uploading an existing file»** کلیک کنید.
4. **تمام محتویات پوشه `manjarvpn`** (شامل پوشه `.github`، فایل‌های `main.py`، `engine.py`، `requirements.txt` و …) را بکشید و رها کنید → **Commit changes**.
5. به تب **Actions** بروید؛ بیلد خودکار شروع می‌شود (حدود ۳ تا ۵ دقیقه).
6. روی آخرین اجرا (سبز رنگ ✓) کلیک کنید → پایین صفحه بخش **Artifacts** → دانلود `ManjarVPN-windows-exe` → فایل zip را باز کنید → `ManjarVPN.exe`.

> 💡 هر بار که کد را تغییر دهید (Commit جدید)، exe تازه ساخته می‌شود. با زدن تگ (مثلاً `v1.0`) نسخه در بخش **Releases** هم منتشر می‌شود.

## 📱 استفاده

1. `ManjarVPN.exe` را اجرا کنید (اگر SmartScreen هشدار داد: More info → Run anyway؛ هشدار آنتی‌ویروس برای فایل‌های PyInstaller رایج است و False Positive محسوب می‌شود).
2. دکمه سبز **«اتصال خودکار»** را بزنید.
3. برنامه به ترتیب:
   - ✅ اینترنت مستقیم شما را چک می‌کند
   - 📥 کانفیگ‌ها را از **۳۰ منبع زنده** دریافت می‌کند (آپدیت روزانه)
   - 🏓 صدها کانفیگ را **به‌صورت موازی** از نظر پینگ تست می‌کند
   - 🎯 کم‌پینگ‌ترین‌ها را **تست عمیق** می‌کند: با همان کانفیگ **یوتوب، اینستاگرام و تلگرام را واقعا باز می‌کند** + **سرعت واقعی دانلود و آپلود** می‌سنجد (دانلود از Cloudflare)
   - 🔌 به سروری وصل می‌شود که **هم پینگ و هم سرعت بهتر است و سایت‌ها را واقعا باز کرده**؛ بعد **پروکسی سیستم ویندوز** را روی `127.0.0.1:10809` (HTTP) و `127.0.0.1:10808` (SOCKS) تنظیم می‌کند
4. برای قطع، همان دکمه (قرمز) را بزنید؛ پروکسی سیستم هم خاموش می‌شود. بستن برنامه (✕) هم همه‌چیز را تمیز می‌کند — حتی وسط تست.

## 🔧 تنظیمات (در فایل `engine.py`)

| ثابت | پیش‌فرض | توضیح |
| --- | --- | --- |
| `MAX_TEST_NODES` | `800` | حداکثر تعداد کانفیگی که پینگ‌تست می‌شود (بیشتر = کامل‌تر ولی کندتر) |
| `MAX_XRAY_LATENCY_TESTS` | `380` | سقف تست پینگ واقعی بعد از پیش‌فیلتر |
| `CONCURRENT_TESTS` | `48` | تست‌های همزمان پینگ |
| `DEEP_POOL` / `DEEP_TARGET` | `40` / `12` | چند کاندیدِ کم‌پینگ تست عمیق (سایت‌ها + دان/آپ) شوند / حداقل چند نتیجه کامل |
| `SITE_TARGETS` | یوتوب، اینستاگرام، تلگرام | سایت‌هایی که با هر کاندید واقعا باز می‌شوند |
| `TOP_SPEED_TESTS` | `8` | در حالت fallback، چند کانفیگِ برتر پینگ تست سرعت ساده شوند |
| `SUBSCRIPTION_SOURCES` | ۳۰ منبع | لیست منابع؛ می‌توانید لینک اشتراک خودتان را اضافه کنید |

زمان کل تست معمولاً **۲ تا ۵ دقیقه** است.

## 🩺 عیب‌یابی

- **«هیچ کانفیگی دریافت نشد»**: دسترسی به گیت‌هاب قطع است؛ برنامه خودش از آینه‌های جایگزین (ghproxy) تلاش می‌کند. در ساعات اختلال، چند بار دکمه را بزنید.
- **«هیچ کانفیگ سالمی پیدا نشد»**: ساعات اختلال شدید فیلترینگ؛ یک ساعت دیگر تلاش کنید یا `MAX_TEST_NODES` را بالا ببرید.
- **پروکسی روشن است ولی صفحه باز نمی‌شود**: حالا نگهبان خودش تونل را در چند ثانیه بازسازی می‌کند؛ اگر نشد، قطع و اتصال دوباره بزنید.
- **حذف دستی پروکسی**: Settings ویندوز → Network → Proxy → Use a proxy server را خاموش کنید.

## ⚠️ هشدار امنیتی

سرورهای رایگانِ عمومی **ناشناس و غیرقابل‌اعتماد** هستند؛ تراکنش بانکی و ورود به حساب‌های حساس را از طریق آن‌ها انجام ندهید. فقط کدها را از مخزن رسمی خودتان بیلد بگیرید. استفاده از VPN در برخی کشورها محدودیت قانونی دارد — مسئولیت استفاده با خود شماست.
