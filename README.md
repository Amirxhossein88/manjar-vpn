# 🛡 ManjarVPN

برنامه‌ای برای ویندوز با **یک دکمه**: اینترنت شما را خودش بررسی می‌کند، کانفیگ‌های رایگان عمومی دنیا (جمع‌آوری‌شده از کانال‌های تلگرامی توسط مخازن معتبر) را دریافت و از نظر **سلامت، پینگ و سرعت واقعی** تست می‌کند و سپس به **بهترین کانفیگ** وصل می‌شود و پروکسی کل سیستم ویندوز را روشن می‌کند.

## ⚙️ چی درست می‌شود؟

فایل `ManjarVPN.exe` (تک‌فایل، بدون نیاز به نصب پایتون) که **هسته Xray داخلش باندل شده** و ساختنش با **GitHub Actions** به‌صورت خودکار انجام می‌شود.

## 🚀 ساخت exe با GitHub Actions — روش بدون گیت (ساده)

1. وارد [github.com](https://github.com) شوید و ثبت‌نام/ورود کنید.
2. دکمه `+` بالا سمت راست → **New repository** → اسم دلخواه (مثلاً `manjarvpn`) → Public → **Create repository**.
3. در صفحه جدید روی **«uploading an existing file»** کلیک کنید.
4. **تمام محتویات پوشه `manjarvpn`** (شامل پوشه `.github`، فایل‌های `main.py`، `engine.py`، `requirements.txt` و …) را بکشید و رها کنید → **Commit changes**.
5. به تب **Actions** بروید؛ بیلد خودکار شروع می‌شود (حدود ۳ تا ۵ دقیقه).
6. روی آخرین اجرا (سبز رنگ ✓) کلیک کنید → پایین صفحه بخش **Artifacts** → دانلود `ManjarVPN-windows-exe` → فایل zip را باز کنید → `ManjarVPN.exe`.

> 💡 هر بار که کد را تغییر دهید (Commit جدید)، exe تازه ساخته می‌شود. با زدن تگ (مثلاً `v1.0`) نسخه در بخش **Releases** هم منتشر می‌شود.

## 🚀 روش با گیت

```bash
git init
git add .
git commit -m "ManjarVPN v1.0"
git branch -M main
git remote add origin https://github.com/USERNAME/manjarvpn.git
git push -u origin main
```

سپس همان مراحل ۵ و ۶ بالا.

## 📱 استفاده

1. `ManjarVPN.exe` را اجرا کنید (اگر SmartScreen هشدار داد: More info → Run anyway؛ هشدار آنتی‌ویروس برای فایل‌های PyInstaller رایج است و False Positive محسوب می‌شود).
2. دکمه سبز **«اتصال خودکار»** را بزنید.
3. برنامه به ترتیب:
   - ✅ اینترنت مستقیم شما را چک می‌کند
   - 📥 کانفیگ‌ها را از ~۱۰ منبع معتبر دریافت می‌کند (ده‌ها کانال تلگرامی، آپدیت هر ۱۵ دقیقه)
   - 🏓 صدها کانفیگ را **به‌صورت موازی** از نظر پینگ تست می‌کند
   - 🚀 سریع‌ترین‌ها را **تست سرعت واقعی** می‌کند (دانلود از Cloudflare)
   - 🔌 به بهترین وصل می‌شود و **پروکسی سیستم ویندوز** را روی `127.0.0.1:10809` (HTTP) و `127.0.0.1:10808` (SOCKS) تنظیم می‌کند
4. برای قطع، همان دکمه (قرمز) را بزنید؛ پروکسی سیستم هم خاموش می‌شود. بستن برنامه هم همه‌چیز را تمیز می‌کند.

## 🔧 تنظیمات (در فایل `engine.py`)

| ثابت | پیش‌فرض | توضیح |
| --- | --- | --- |
| `MAX_TEST_NODES` | `400` | حداکثر تعداد کانفیگی که پینگ‌تست می‌شود (بیشتر = کامل‌تر ولی کندتر) |
| `CONCURRENT_TESTS` | `30` | تست‌های همزمان پینگ |
| `TOP_SPEED_TESTS` | `12` | چند کانفیگِ برتر پینگ، تست سرعت واقعی شوند |
| `SUBSCRIPTION_SOURCES` | ۱۰ منبع | لیست منابع؛ می‌توانید لینک اشتراک خودتان را اضافه کنید |

زمان کل تست معمولاً **۲ تا ۵ دقیقه** است.

## 🩺 عیب‌یابی

- **«هیچ کانفیگی دریافت نشد»**: دسترسی به گیت‌هاب قطع است؛ برنامه خودش از آینه‌های جایگزین (ghproxy) تلاش می‌کند. در ساعات اختلال، چند بار دکمه را بزنید.
- **«هیچ کانفیگ سالمی پیدا نشد»**: ساعات اختلال شدید فیلترینگ؛ یک ساعت دیگر تلاش کنید یا `MAX_TEST_NODES` را بالا ببرید.
- **پروکسی روشن است ولی صفحه باز نمی‌شود**: کانفیگ ممکن است وسط کار مرده باشد؛ قطع و دوباره اتصال بزنید (تست تازه انجام می‌شود).
- **حذف دستی پروکسی**: Settings ویندوز → Network → Proxy → Use a proxy server را خاموش کنید.

## ⚠️ هشدار امنیتی

سرورهای رایگانِ عمومی **ناشناس و غیرقابل‌اعتماد** هستند؛ تراکنش بانکی و ورود به حساب‌های حساس را از طریق آن‌ها انجام ندهید. فقط کدها را از مخزن رسمی خودتان بیلد بگیرید. استفاده از VPN در برخی کشورها محدودیت قانونی دارد — مسئولیت استفاده با خود شماست.
